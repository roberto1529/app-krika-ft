# **Frontend - Gestión de Tareas**

## **Descripción**

Este es el frontend de la aplicación de gestión de tareas, construida con React.js. Los usuarios pueden crear, editar, eliminar y gestionar el estado de las tareas de manera eficiente. La interfaz se conecta con el backend a través de API RESTful para manipular los datos.

## **Tecnologías utilizadas**

- **React.js**: Para la construcción de la interfaz de usuario.
- **Axios**: Para realizar peticiones HTTP al backend.
- **React-Select**: Para los selectores personalizados de usuario.
- **Bootstrap**: Para los estilos básicos.
- **React Router**: Para la navegación entre diferentes vistas.
